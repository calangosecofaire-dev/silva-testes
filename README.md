# SILVA TESTES

Jogo de tiro 2D para navegador com:
- Modo solo com bots
- Multiplayer por salas
- Atirar
- Agachar
- Pular
- Correr
- Recarregar
- Controles para PC e celular

## Rodar no computador

1. Instale o Node.js.
2. Abra o terminal nesta pasta.
3. Rode:
   npm install
   npm start
4. Abra http://localhost:3000

## Colocar online

Você pode publicar este projeto em serviços que executem Node.js e suportem WebSocket, como Render, Railway ou Fly.io.

Comando de início:
npm start

Depois da publicação, envie o link gerado pelo serviço para seus amigos.
Para jogarem juntos, todos devem entrar no modo MULTIPLAYER e usar o mesmo código de sala.

## Observação
Este projeto é um protótipo completo e jogável em 2D. Um FPS 3D com gráficos avançados exigiria assets 3D, animações, mapas, áudio e uma engine como Godot, Unity ou Unreal.
